# FRC Robot Code 2026 - Coding Guidelines

## Project Overview

This is an FRC (FIRST Robotics Competition) robot project for the 2026 season, written in Java using WPILib. The project uses CTRE motors (Phoenix 6) and PhotonVision for vision processing.

## Coding Guidelines

### General Behavior
- Do NOT generate tests or documentation unless explicitly requested
- Make minimal, focused changes to accomplish the task
- Follow the existing code style and patterns in this project
- If instructions are unclear or ambiguous, ask clarifying questions before proceeding

### Code Style
- Match the existing naming conventions, formatting, and structure used in this codebase
- Prefer editing existing files over creating new ones when appropriate
- Keep changes small and reviewable

### Dependencies
- Use Gradle and the vendordeps system for managing third-party libraries
- Reference existing vendordeps in the project for compatible versions
